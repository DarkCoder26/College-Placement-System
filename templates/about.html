PROJECT INFORMATION

About this project

A BCA-level web application for managing and analysing campus placement records.

Project description

The College Placement Analysis System helps authorised college staff maintain student placement information, find records quickly, review placement outcomes, and export reports. Statistics are calculated from the current SQLite database.

Problem statement

Manual spreadsheets can become inconsistent, difficult to search, and slow to summarise. This application centralises records and applies consistent validation and calculation rules.

Objectives

  • Maintain accurate student placement records through CRUD operations.
  • Search and filter by student, department, status, and graduation year.
  • Calculate placement rates and package summaries correctly.
  • Export student and analytics data as CSV files.
  • Demonstrate Python, Flask, SQL, SQLite, Pandas, HTML, and CSS in one project.

Technologies

Python 3FlaskSQLiteSQLPandasHTML5CSS3Jinja2Pytest

Main modules

Dashboard, student management, search and filters, placement analytics, CSV reports, database layer, and automated tests.

Limitations

This educational version has no login or role-based permissions, and it does not import records from a college ERP. The development secret key is not suitable for deployment.

Future enhancements

Add authentication and authorisation, Excel/PDF reports, audit logs, bulk import with validation, configurable academic years, and deployment behind HTTPS after a security review.

Security note: This is an educational application. Do not expose it publicly or use real sensitive student data without authentication, access controls, backups, HTTPS, and a security review.
